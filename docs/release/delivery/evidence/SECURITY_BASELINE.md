## PWA baseline

No manifest, service-worker registration, service worker/cache code or connectivity UI is presently implemented in root/mirrored app. Both Vite configs deliberately set publicDir:false because public/assets/aistudio contains historical implementation/source artifacts, including documents and schema/code. **Never enable the entire historical public tree just to serve PWA assets.** Use a dedicated approved asset directory/plugin-generated outputs, verify both build artifacts exclude historical files. Root index and mirrored frontend should preserve deployment base behavior; root Pages builds with VITE_BASE_PATH:'./', so root-only absolute SW/manifest paths would break subpath deployment.

Current sensitive API boundary globally returns Cache-Control:no-store; timing/F01/payment clients use no-store. Birth/chart state is React memory, not localStorage/IndexedDB by the inspected search. New worker must preserve that privacy model. Current native/cloud release gates remain unchanged; offline UI must not fabricate native calculations or present stored personal timing as fresh/verified. Network connectivity signals alone do not prove API availability.

## Required independent candidate acceptance

1. Manifest/install: valid same-origin manifest/name/start_url/scope/display and icons; install affordance only when supported; truthful browser support instructions and no claim install succeeded from a click. Verify root and project subpath builds in production. Restrict worker scope to this application path; never scope a project worker over other origin applications.
2. Cache allowlist: only explicitly build-owned immutable JS/CSS/icons/static shell, same-origin GET200 basic responses, no query-bearing URLs. No /api, auth, checkout, capability, health, user navigation URLs, POST bodies, birth/chart/rule results, tokens/cookies, requests with Authorization, or third-party responses in CacheStorage/IndexedDB. Do not treat Cache-Control:no-store as automatically honored by custom Cache API; enforce the policy in worker logic. Test attacker/path/query variants and response-type/status failures.
3. Navigation offline: no caching arbitrary HTML navigation responses or personalized server responses. If offline fallback exists, use a build-produced neutral shell and clearly show limited/offline state. Never synthesize successful API JSON. API/network failures stay unavailable. Online status means connectivity, not native service readiness or scientific validation.
4. Lifecycle/update: version deterministic cache names tied to artifact; clean only this app-owned namespace; old version remains usable until new complete install succeeds. Failed install preserves old cache. Prompt user before reload so in-memory birth form data is not silently lost. No unconditional skipWaiting/reload loops. Verify new waiting worker, explicit activation, controllerchange, duplicate events and reconnect behavior; record actual browser runs.
5. Worker security: exact paths resolved under registration scope, reject cross-origin/cache-poisoning requests, no broad runtime fetch cache. Registration failure gracefully leaves app functional. Serve actual worker JS MIME and cache/update semantics, not SPA HTML fallback. Dedicated /service-worker.js unknown path should not accidentally masquerade as HTML. Secure-context requirement (localhost test exception) documented; no claim deployed HTTPS exists.
6. UX/accessibility: persistent understandable offline/limited status; keyboard-operable dismiss/install/update controls, accessible status live region without repeated announcements; no essential form disable based solely navigator.onLine. Mobile+desktop synthetic browser coverage distinct from physical install/real-user UAT. Mirror source/build behavior verified.
7. Release evidence: exact candidate SHA, original diff and production browser commands/results, root/subpath offline/update tests and cache enumeration after synthetic birth/API interactions. Record NOT RUN for physical devices/install surfaces unavailable. Broader domain/private hosting/performance/UAT gates remain separately open.
