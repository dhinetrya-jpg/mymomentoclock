# PAY-P0-02 scoped security audit

Default remains fail closed. No real identity/provider registration, no client-identity header trust, no fixture switch, no live key, no production activation or public internal fulfillment. Provider construction requires explicit approval and valid test-mode configuration; namespace scopes brand/account/environment. Real account/key ownership has not been independently verified.

Transport uses fixed HTTPS host, Basic auth, redirect refusal, bounded response/deadline/retry and redacted errors. Provider IDs/receipt/values/currency/captured state/account and refund totals validated. Webhook raw signature verified before parsing/API/DB work, minimal evidence/raw digest retained, no card/body retention. Customer/order/access SQL remains authenticated and durable. Server-priced checkout exposes test public key/order only and ignores browser success for authorization.

Critical sweep corrections: (1) do not invent ordered revisions; explicit snapshot lattice and terminal holds; (2) non-idempotent create requires durable first-attempt marker/receipt recovery with no blind POST retry; (3) review hold separate from old status enum preserves migration re-execution; (4) omitempty new event fields preserve PAY01 fingerprints, checked by golden regression; (5) raw digest makes conflicting callback bytes visible; (6) notifications cannot fulfill and are cleaned only after authoritative processing; (7) strict ID/value/state parsing and processed refund sum, not refund callback alone.

Remaining gates: current hosted API contract/test-method verification; provider approval/real account/keys; real identity; genuine sandbox payment/webhook/refund; provider dispute/reversal mapping; live paging/eventual-consistency/retry/secret-rotation semantics; network/TLS/ingress/CNI/backup/role rollout; approved catalog/refund/retention policy. This audit does not certify production security or a real provider. Reversals are not silently treated as refunds and unsupported events never grant, but that missing lifecycle is an activation blocker.

All mock API servers, synthetic identities/keys and control routes are _test.go/tests only. The adapter base URL is fixed in production; tests can modify its unexported field in the same test package. Nothing configures a production fake URL or paid success. No credentials logged/committed. Financial evidence retention must keep idempotency/replay tombstones and follow owner/legal policy from PAY01.
